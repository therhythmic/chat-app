# Chat App

One simple, clean inbox where a team talks. It pulls in Messages (through the app's own number in group texts), Slack, Telegram and Messenger (Pages), and organizes everything three ways: by person (Threads), by project, and by app (Sources). AI suggests the project for each message and asks when it isn't sure.
